# Canon Status Matrix — Levels 0–99

Data-base: 2026-10-01.

Este documento separa existência no índice, estado editorial e confiabilidade dos detalhes.

| Faixa | Estado | Regra |
|---|---|---|
| 0–50 | primeira passagem + auditoria progressiva | revisar campos e conexões |
| 51–70 | mistura de current, trimmed e rewrite | preservar divergências |
| 71–90 | primeira passagem estruturada | revisar conectividade, mídia e subníveis |
| 91–92 | current | documentação detalhada |
| 93 | under rewrite | tratar dados como provisórios/históricos |
| 94 | current | manter divergências internas |
| 95 | current/em construção | não inferir rotas |
| 96 | current | preservar caráter literário |
| 97–99 | trimmed/open for rewrite | marcar dados históricos |

## Estados permitidos
current; trimmed/open for rewrite; under rewrite; historical; not confirmed.

## Precedência
1. Página oficial do nível.
2. Subpágina oficial vinculada.
3. Página oficial de entidade/base.
4. Logs/documentos oficiais.
5. Fórum somente como contexto editorial.

## Regra de divergência
Versões incompatíveis são preservadas separadamente. Nunca criar uma terceira versão por inferência.
