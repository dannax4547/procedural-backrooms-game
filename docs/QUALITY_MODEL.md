# Modelo de qualidade editorial

## Objetivo

Medir a qualidade das fichas sem confundir ausência de informação com erro factual.

## Métricas

### Seções
Cada documento deve possuir as dez seções obrigatórias.

### Auditoria marcada
Conta os itens `[x]` dentro de `## Auditoria`.

### Incertas/pendências
Conta marcadores editoriais como:
- Não documentado;
- Não confirmado;
- pendente;
- não consolidado;
- desconhecido.

Esses termos **não são falhas automaticamente**. Eles mostram onde a pesquisa ainda pode avançar.

### Mídia
A ferramenta verifica se a seção de mídia registra algum status de licença/origem. Uma licença pendente continua sendo uma pendência editorial.

## Regra

Qualidade alta não significa “zero desconhecidos”. Em documentação de fenômenos ficcionais e versões históricas, ocultar incertezas é pior do que registrá-las.
